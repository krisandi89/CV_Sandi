# Portfolio Website - Krisandi Saptyanto

Website portfolio profesional dengan tema Modern Blue.

## 🚀 Quick Start

### Jalankan Lokal
```bash
# Pakai Python (sudah terinstall di Mac)
python3 -m http.server 8000

# Buka di browser
# http://localhost:8000
```

### Deploy ke GitHub Pages
1. Push ke branch `update-project-list-4694880761366021028`
2. Website akan live di GitHub Pages

---

## 📝 Cara Edit Content

Semua konten website ada di file `src/content.js`.

### Edit Profile
```javascript
profile: {
    name: "Nama Anda",
    headline: "Jabatan Anda",
    ...
}
```

### Tambah Project Baru
Lihat panduan lengkap di: `directives/update_projects.md`

---

## 📁 Struktur File

```
├── index.html          # Halaman utama
├── styles.css          # Styling (Modern Blue theme)
├── assets/images/      # Gambar profile & project
├── src/
│   ├── content.js      # 📝 EDIT INI untuk update konten
│   ├── main.js         # Logic website
│   └── three-scene.js  # Animasi 3D background
└── directives/
    └── update_projects.md  # Panduan tambah project
```
