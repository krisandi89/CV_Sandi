### B. Visual Identity (Inti Brand)

#### 1. Color System

**Primary Palette**

- Deep Navy / Midnight Blue (background utama)
    
- Neon Blue / Cyan (accent, CTA, highlight)
    
- Soft Teal / Aqua (secondary accent)
    

**Color Psychology**

- Biru gelap → trust, stabilitas, profesional
    
- Neon blue → teknologi, futuristik, inovasi
    
- Gradien halus → modern & premium
    

> Prinsip: **dark UI dengan glow ringan, bukan kontras keras**

---

#### 2. Typography

- **Headline**: Sans-serif modern (Inter / Poppins / SF Pro style)
    
- **Body**: Clean sans-serif, ringan, high readability
    
- **Weight usage**:
    
    - Headline: SemiBold – Bold
        
    - Subheadline: Medium
        
    - Body: Regular
        

Tone teks:

- Percaya diri
    
- Tidak agresif
    
- Tidak terlalu marketing
    

---

#### 3. UI Style

- Rounded corners (medium radius)
    
- Card-based layout
    
- Soft shadow + inner glow
    
- Glass / neumorphism ringan (tidak berlebihan)
    
- Icon monoline futuristik
    

---

#### 4. Imagery Style

- Profile image: **tech / futuristic mood**
    
- Neon light (cyan / purple hint)
    
- Dark background
    
- Close-up / portrait
    
- No busy background
