## 2024-07-25 - Modal Accessibility
**Learning:** Found a common accessibility issue where a modal was not dismissible via the 'Escape' key and the close button lacked an ARIA label. This is a recurring pattern in simple, static websites.
**Action:** Always check modals for both keyboard and screen reader accessibility. Ensure interactive elements have proper labels and that essential keyboard interactions, like closing a modal with 'Escape', are implemented.
